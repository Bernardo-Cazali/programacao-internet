Página navegação Web

Este projeto consiste em uma página web simples focada na navegação por links, estruturada através de listas HTML. O objetivo principal é demonstrar como organizar conjuntos de links e menus de forma semântica e acessível.

A Internet é a infraestrutura física global — uma rede gigantesca de computadores e cabos interconectados que permite o tráfego de dados. Já a Web (World Wide Web) é apenas um dos serviços que roda sobre a Internet, utilizando o protocolo HTTP para permitir o acesso a sites, páginas e links interligados por meio de navegadores.
