História da Internet e da Web

"A Web não é um produto acabado, mas um processo contínuo de evolução."

— Tim Berners-Lee, criador da World Wide Web no CERN.

Linha do Tempo Textual e Evolução

A história das redes de computadores começou com a necessidade de conectar sistemas distantes. A precursor da Internet foi a ARPANET, criada nos anos 1960. Com o tempo, a adoção dos protocolos TCP/IP e do sistema de nomes DNS permitiu que a rede se expandisse globalmente.

Mais tarde, o cientista Tim Berners-Lee revolucionou a comunicação ao inventar a World Wide Web, criando a linguagem de marcação HTML, o protocolo de navegação HTTP, além do primeiro navegador e do primeiro servidor web da história.

Diferente da Web 1.0 (onde os usuários apenas liam conteúdo estático), as aplicações Web modernas são totalmente interativas e dinâmicas (exemplo da molécula de água H2O e fórmulas como X2 em sistemas web).

Glossário de Conceitos Fundamentais

ARPANET
Primeira rede operacional de computadores à base de comutação de pacotes, criada pela DARPA.
TCP/IP
Conjunto de protocolos que serve como base para a transmissão de dados na Internet.
DNS
Sistema que traduz nomes de domínios legíveis (ex: site.com) em endereços IP numéricos.
Tim Berners-Lee
Cientista britânico no CERN que inventou a World Wide Web em 1989.
Navegador e Servidor Web
O navegador faz requisições via HTTP e o servidor web processa e entrega as páginas HTML ao usuário.

Marcos Históricos da Web e da Internet

Resumo dos principais marcos da evolução tecnológica
Ano Acontecimento Importância para a Web ou Internet
1969 Criação da ARPANET Surgimento da primeira rede de computadores interconectados.
1983 Adoção do TCP/IP Padronização dos protocolos fundamentais da Internet.
1983 Criação do DNS Facilitou a navegação ao substituir IPs numéricos por nomes de domínio.
1989 Invenção da World Wide Web Tim Berners-Lee propõe o sistema de hipertexto no CERN.
1991 Lançamento do HTML e HTTP Surgimento dos padrões de criação de páginas e transferência de dados.
1993 Navegador Mosaic Popularizou o uso da Web trazendo interface gráfica com imagens.
